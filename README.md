# Discord_bot_for_Server_of_Siege
## 「シージ民の住処」用自作botファイル置き場

### 「シージ民の住処」のサーバ管理自動化用の自作botファイル置き場です
    - このリポジトリを閲覧できるのはサーバ運営陣に限られます。
    - 一般ユーザに閲覧許可を出したい場合は「BOT管理者」に許可を得てください。
    - 特段の事情がない限り一般ユーザの閲覧はできません。
    - bot毎にフォルダを作成し、フォルダ名はbot名にしてください。仮の名前であればフォルダ名の最後に「（仮称）」とつけ、正式名称が決まったらリネームして「（仮称）」を外してください。
    - botの命名規則は特に設けませんが、必ずフォルダ内に「read me」ファイル（マークダウンかテキスト形式のもの）を作成し、機能と操作方法が分かるようにしておいてください。
    - botコマンドを設定する際、「#」「!」「/」でコマンドを始めるbotがとても多いので、できれば別の記号を使うようにして頂けると、無関係なbotの誤応答を防止できます。
    - リポジトリ内のbotを一部他サーバに合わせて書き換えた上で他サーバで使いたい場合は、作成者の許可を得てからにしてください。共同作成botの場合は作成者全員の許可を得てください。
    - ファイルの修正や改造は、自分用のブランチを作成して、そこで行うようにしてください。ブランチには自分のdiscordネームをつけ、誰のブランチか分かるようにお願いします。レビューやテストを経て完成したものはメインブランチにpullします。
    - 改変したものはすぐにpullせず、一旦自ブランチでcommitし、サーバ内でその旨周知してください。BOT管理人に周知なしで突然pull requestしないでください。
    - 既存botの改良などは、一言作成者に声がけしてから行うようにしてください
    - サーバの為に自作した、あるいは自作途中のbotがあれば、このリポジトリに新しくフォルダを作ってどんどんupお願いします。
    - レビューを求められたらできるだけ快く受けてあげましょう
